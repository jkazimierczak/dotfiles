# jkazimierczak's dotfiles

This repo houses dotfiles and various scripts that help me get my machine up to speed with tools and configs I use day-to-day.

# Installation

```bash
sudo apt install curl git -y
sh -c "$(curl -fsLS https://get.chezmoi.io)" -- init --apply jkazimierczak
```

or if retrying, for whatever reason

```bash
./bin/chezmoi init --apply jkazimierczak
```
